
# PLC Projects 🤖

A collection of **Programmable Logic Controller (PLC)** projects demonstrating foundational automation and industrial control skills.  
These projects showcase **ladder logic programming, timers, counters, and process control simulations**, perfect for building a strong industrial automation portfolio.

---

## 🚀 Key Highlights

- Implemented **timers, counters, and set/reset logic** for industrial automation tasks  
- Built **traffic light and water level control simulations** using PLC logic  
- Developed **7-segment display and assignment-based projects** to strengthen control system understanding  
- Practiced **ladder logic programming** compatible with common PLC platforms (Siemens, Allen-Bradley, Codesys)

---

## 🗂 Project Overview

| Project Folder | Description |
|----------------|-------------|
| `7_Segment_Display` | Drive a 7-segment display with PLC outputs |
| `Assignment1` | Foundational control tasks for learning PLC logic |
| `Counter` | Counter-based logic implementation |
| `On_Timer` | On-delay timer example |
| `Set_Reset` | Set/Reset latch logic |
| `Timer` | Timer-based control example |
| `Traffic_Light` | Traffic light control simulation |
| `Water_Level_Indicator` | Water level detection and control logic |
